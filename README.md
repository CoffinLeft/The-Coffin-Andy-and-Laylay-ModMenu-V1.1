# COFFIN COMPANION

Мод-меню для одиночной игры **The Coffin of Andy and Leyley** (Steam, RPG Maker MV):
чит-функции, спидран-таймер, режим стримера и переназначение клавиш.

> ⚠️ Только для одиночной игры. Только для собственной копии из Steam.
> Мод изменяет файлы игры (создаются резервные копии). Разработчикам игры и
> модерации это может быть не по душе — используй на свой риск.

---

## Требования

- Windows 10/11 (64-бит)
- Steam установлен и выполнен вход
- Купленная в Steam игра The Coffin of Andy and Leyley (установлена, хотя бы раз запущена)

---

## Установка и запуск

1. Скачай `AndyLeyleyCheatMenuSetup.exe` со страницы Releases.
2. Запусти файл (если Windows предупреждает о неизвестном издателе —
   «Подробнее» → «Выполнить в любом случае»).
3. Программа сама:
   - найдёт игру в библиотеках Steam;
   - создаст резервные копии изменяемых файлов (`*.bak`);
   - установит мод-файлы в папку игры;
   - запустит игру через Steam.
4. Играй. Никаких папок вручную искать не нужно.

### Если игра не нашлась автоматически

Обычно так бывает, если игра стоит в нестандартной библиотеке. Тогда:

1. Открой Steam.
2. Правой кнопкой мыши по игре → **Управление** → **Просмотреть локальные файлы**.
3. Если мод просит указать папку вручную — выбери именно эту папку
   (в ней лежит `Game.exe` и папка `www`).

### Повторный запуск

Просто запускай EXE каждый раз — он перепроверит установку и запустит игру.
Можно запускать и обычным способом через Steam, мод уже установлен.

## Управление в игре (по умолчанию)

| Клавиша        | Действие                          |
|----------------|-----------------------------------|
| **F6**         | Сквозь стены (вкл/выкл)           |
| **F7**         | Главное меню мода                 |
| **Ctrl+F6**    | Быстрый текст (вкл/выкл)          |
| **F8**         | Пропуск диалогов (вкл/выкл)       |
| **Ctrl+F8**    | Быстрая ходьба (вкл/выкл)         |
| **F9**         | Таймер и настройки / стример-режим|
| **Ctrl+F9**    | Быстрое вкл/выкл режима стримера  |
| **F10**        | Переназначение клавиш             |
| **Ctrl+Shift+F9**  | Записать сплит таймера        |
| **Ctrl+Shift+F10** | Сбросить и начать забег       |
| **Ctrl+Shift+F11** | Финиш забега                  |

Все клавиши меняются в меню **F10** и сохраняются между запусками.
В левом нижнем углу всегда видно текущие бинды и состояние функций.

## Возможности

**Читы:** сквозь стены, быстрый текст, пропуск диалогов, быстрая ходьба,
меню Steam-достижений игры.

**Спидран-таймер:**
- старт при появлении на карте или при первом сообщении (настройка);
- паузы: в диалогах, при переходах между локациями, в меню — настраиваются
  отдельно; на паузе таймер становится серым;
- сплиты, личный рекорд (хранится локально), сброс и финиш.

**Режим стримера:**
- замена мата в диалогах и вариантах выбора (свой список слов и замена);
- фильтр крови: перекраска красных пикселей в выбранный цвет или размытие
  картинок, чьи имена файлов содержат заданные слова;
- скрытие служебных HUD-панелей.

Настрой режим **до** начала трансляции: мод не умеет показывать тебе и
зрителям (OBS/Discord) разную картинку — захватывается весь экран игры.

## Удаление

Закрой игру и удали из папки игры (как её найти — см. выше):

- `www\js\plugins\AndyLeyleyCheatMenu.js`
- `www\js\plugins\CoffinCompanion.js`
- из файла `www\js\plugins.js` — строки с `AndyLeyleyCheatMenu` и `CoffinCompanion`

Или восстанови резервные копии `*.before_CoffinCompanion.bak`, убрав `.bak`
из имени.

## Проблемы и решения

**EXE пишет, что игра не найдена.**
Убедись, что игра установлена через Steam и хотя бы раз запускалась.
Проверь антивирус — он мог заблокировать чтение папок Steam.

**После проверки целостности файлов Steam мод пропал.**
Это нормально: Steam восстановил оригинальные файлы. Просто запусти EXE ещё раз.

**Игра не запускается / чёрный экран после установки.**
Восстанови резервные копии (см. «Удаление») и напиши issue с описанием.

**Антивирус ругается на EXE.**
Файл собран Open Source скриптом, исходники в репозитории — можешь собрать
сам. Ложные срабатывания на самодельные EXE встречаются часто.

---

## Честные ограничения

- Достижения Steam, разблокированные модом, **нельзя вернуть назад**.
- Фильтр крови работает по именам файлов: если кровь в файлах с «нейтральными»
  названиями, добавь эти названия в настройки.
- Мод не работает в сетевой игре (её нет) и не предназначен для обмана
  других игроков.
- Автор мода не связан с разработчиками игры. Игра购买ляется в Steam.
